# Nuclear Timeline

A visualization of nuclear detonations, stockpiles, and their proliferation across the world since 1945.

It includes:
* Chart.js bar and line graphs displaying test data
* React Three Fiber visualization of the globe and lat/long coordinates for each event
* Timeline of historical events, descriptions, and images and gifs

## Setup

* Node v24+
* `pnpm`
* Run `pnpm install`
* Then `pnpm dev` starts the dev server
